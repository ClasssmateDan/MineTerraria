# Dimensional Terraria

在真实 Terraria / tModLoader 中实现二维与三维切换的单人模组原型，包含 Minecraft 风格人物、羊、生成蛋、剑及金属／宝石压缩方块。

## 当前版本 v0.23.0

修复进入三维后Boss因为没有存活玩家目标而离场：三维期间Boss与已存在的关联部件保留AI阶段和生命，暂缓攻击／移动决策并阻止距离／计时清除；世界、普通生物、受伤与掉落继续运行。阶段转换在返回二维后继续。返回附近可恢复索敌，返回很远处不跨地图重新锁定玩家；真正死亡不受保留规则保护。该规则不提供存档保存Boss的功能。

移除三维左上角操作说明及F1提示开关。物品说明改为HJSON真实多行文本，删除字面`\n`、素材来源、调试用途与重复配方；护甲只保留套装说明，普通压缩方块不再重复描述合成配方。F3按需显示坐标的功能保留。

## 三维武器攻击

在模组配置中切换 **“启用三维武器攻击”**，默认开启。选择剑、短剑、矛、弓、枪或普通魔法武器，按住左键朝准星攻击。距离包含离开地图的Z纵深，因此普通近战必须飞近目标；初始32格距离可使用远程、魔法，或已适配的天顶剑／飞龙。准星指向可攻击敌怪时变绿并显示名称、生命，命中时闪色并播放挥动或射击轨迹。

受伤生物头顶显示血条和当前／最大生命，移开准星后仍可看到；准星指向的满血目标也会显示。受击时生物短暂闪红、出现上浮伤害数字，暴击使用较大的金色数字；玩家命中还显示准星周围的交叉标记和更明显的命中火花。血条和飘字使用三维相机投影，检查地形、迷雾和屏幕范围。暂停时停止计时，退出三维清除飘字；关闭生物显示时也隐藏这些信息。

每次操作只选择一种动作：更近的可攻击敌怪优先；否则当前工具能处理准星方块时挖掘；其余情况持武器攻击。两种操作共用冷却，避免同一次左键既挖方块又造成伤害。可分别关闭挖掘、拾取与攻击，权限仍集中在`DimensionPlayer.CanInteractIn3D`，方便后续加入装备条件。

普通攻击采用单目标直线即时命中，范围为普通近战4.5格、远程／魔法48格；天顶剑与飞龙则使用上述移动弹道。方块、背景墙及探索迷雾会阻挡瞄准，友好NPC和不可受伤目标不会被选中。使用原版武器伤害、攻速、暴击、击退、弹药选择与消耗、魔力费用和命中钩子；敌怪按原版处理死亡和掉落。三维期间单独继续原版魔力恢复，暂停时停止。缺少弹药或魔力时不造成伤害，并显示提示。

这还不是完整的三维原版弹幕系统：除已适配的天顶剑与飞龙外，其他武器和弹药的穿透、爆炸、多发、追踪、特殊弹道与召唤效果尚未复现。持续引导武器、召唤武器及投掷消耗品暂不开放；不支持基础攻击的武器显示提示。剑、镐等近战的手臂动作继续使用共同的挥动反馈。

- **调试：在当前位置生成羊**：生成50生命的友好羊，三维时使用当前XY的地图投影，保留世界边界和探索限制。
- **调试：生成铁傀儡**：在附近地面生成500生命的中立守卫，约需3格宽、5格高的空间；三维时保留探索限制。可先在二维用弱武器测试反击，再进入三维观察它与附近敌怪交战。

主菜单、多人游戏或角色死亡时不执行调试操作，按钮行显示原因。可先在二维空地领取武器、生成假人，再进入三维测试：远程在48格内、近战在4.5格内有效。

## 三维挖掘与拾取

在模组配置中分别调整 **“启用三维挖掘”** 和 **“启用三维拾取”**，默认均开启。关闭后保留观察、飞行和返回功能。

先飞近地图，把准星对准目标。6格内出现轮廓后，在快捷栏选择对应工具并按住左键：镐挖普通方块，斧砍树木，锤处理背景墙和原版要求锤的物体。挖掘复用原版工具强度、速度、累计损伤和保护规则，掉落物由原世界生成；挖掘位置附近的渲染区块会优先刷新。背景墙会在前景方块移除后成为准星目标。斜坡、非实心家具和植物的射线形状暂按简化体积处理。

南瓜、蘑菇等原版可挥砍采集的植物接受镐、斧、锤及可挥砍的近战武器，使用原版切割流程处理自然保护、特殊工具和掉落；其他易破坏物也遵循原版属性。普通矿石、树木和背景墙继续要求对应工具，不会用植物规则绕过保护。每次有效操作触发手臂／工具挥动，在命中位置飞出目标贴图的碎屑；碎屑在三维空间中下落、旋转并淡出。工具的静止朝向以相机竖直方向校准，不再随手臂向左倾倒；挥动时保留握点连接。

掉落物以原版贴图显示在地图平面上；三维身体距物品默认6格以内时自动拾取，包含离开地图的Z距离。“三维拾取半径”可调整为2至12格。保留原版拾取延迟、物品限制、堆叠和背包剩余处理；背包满或不能拾取时，物品继续留在世界中。拾取范围不会以玩家的二维出发位置代替，也不能隔探索迷雾收取物品。

E背包、Esc暂停菜单、聊天和窗口失焦期间停止交互。进入三维或关闭菜单后，需要先松开左键，再按住以开始挖掘或攻击。每次挖掘、拾取与攻击都通过 `DimensionPlayer.CanInteractIn3D(DimensionAction)` 取得权限；后续可在这里加入装备、增益或世界进度条件，无需改写准星和背包逻辑。

## 探索迷雾

模组配置中的 **“启用三维探索迷雾”** 默认开启。开启后，仅显示当前角色在当前世界原版地图中已探索的区域；未探索区域显示为暗色遮挡，隐藏其中的地形和生物。树冠等跨格图像会按已探索格裁切。

装饰性群系背景不受这项限制，投影位置未探索时仍正常切换；它不会扩大地图探索记录，也不会解除对真实地形与落点的迷雾限制。

按 V 或菜单中的“在此处返回二维”返回时，完整角色覆盖的所有格子都必须已探索。未探索位置显示专门的拒绝提示；B 返回出发位置始终保留为恢复入口。关闭迷雾后，取消地形遮挡与探索落点限制，原有的碰撞、液体和世界边界判定继续生效。

每次进入三维时读取一次原版地图记录，三维飞行不会扩大这份记录。回到二维继续探索后，再进入三维就会显示新区域。探索记录按角色和世界区分；尚无地图记录的角色会看到大面积迷雾。请在二维状态下修改配置，再进入三维。

## 编译

需要 Windows PowerShell 或 PowerShell 7、.NET 8 SDK。无需额外 NuGet 包。

在仓库目录执行：

```powershell
.\scripts\Setup.ps1
.\scripts\Test.ps1
.\scripts\Build.ps1
```

`Setup.ps1` 下载官方 tModLoader **v2026.07.3.0（Terraria 1.4.4.9）** 并验证发布方 SHA-256，仅放入本目录 `.dev`。编译和打包的临时配置、日志、Mods 输出也留在工作目录。此步骤准备开发依赖，不等于安装 Steam 版 tModLoader。

也可以指定已有 tModLoader 安装：

```powershell
.\scripts\Build.ps1 -TmlDirectory 'F:\SteamLibrary\steamapps\common\tModLoader'
```

最终模组：`artifacts/DimensionalTerraria-v版本号.tmod`，例如`artifacts/DimensionalTerraria-v0.12.0.tmod`。同版本重建会另加时间和短标识，旧文件不会被覆盖；构建脚本最后一行给出本次实际输出路径。

1. 在 Steam 安装并运行 [tModLoader](https://store.steampowered.com/app/1281930/tModLoader/)，需要拥有 Terraria。目标为 **1.4.4 稳定分支**，建议先使用上述固定版本验证。

## 原型边界

- 三维模式提供观察、飞行、返回、可选的工具挖掘、拾取与基础准星战斗，尚不支持建造。攻击范围及未适配的武器行为见上文。生物及掉落物沿地图平面显示为二维精灵，尚无三维模型；特殊生物的额外肢体、装备与自定义绘制尚未完整适配。原有弹幕仍在原世界运行，但三维弹幕绘制尚未完整实现。
- 原版刷怪和普通实体活跃范围仍以出发区域为中心。寻敌期间排除玩家，跳过真实玩家的移动、攻击、拾取等更新；临时状态在执行结束或异常时恢复。普通敌怪无目标时使用简化的待机／游荡决策，原版重力、碰撞、动画和增减益继续更新；固定型和蠕虫类原地待机。Boss及关联部件在三维期间留场，暂存AI阶段，死亡与孤立部件清理仍执行；返回二维后恢复正常索敌。没有独立的三维刷怪系统，未承诺兼容其他模组自定义AI。
- 地形使用原版像素贴图、原版帧尺寸与固定环境亮度，支持普通树、宝石树、观赏树、灰烬树和原版棕榈树的树冠／侧枝。尚未完整适配原版动态光照、液体体积、动画、特殊家具自定义绘制和半透明玻璃。
- 每块区块 24×24 格，按距离逐帧构建附近区块并缓存，默认 9×9 区块，可配置视距。缓存持续分批核对地形变化，绘制更新可能稍晚于原世界变化；返回落点始终读取实时世界。远处用雾衔接，不会一次性把整张地图转换成模型。
- 背景墙在三维中有厚度，在二维中不阻挡返回。飞行被限制在整张地图平面的正面，不允许从空隙绕入背面。半砖和平台有简化碰撞；斜坡暂按完整方块处理，可能保守拒绝部分落点。
- 原型的“合法落点”指身体不与方块／平台相交、没有液体并处于边界内，不保证脚下有支撑。高空返回后会正常下落。
- 暂不支持坐骑、抓钩、滑轮、睡眠等状态下进入三维；暂未承诺与大型玩法或绘制模组兼容。

## 结构与验证

- `DimensionalTerraria/Core`：与游戏框架独立的空间判定、分步碰撞、飞行状态。
- `DimensionalTerraria/World`：从原世界读取方块形状、背景墙和液体。
- `DimensionalTerraria/Systems`：输入、单人限制、世界运行与菜单暂停、落点校验和退出恢复。
- `DimensionalTerraria/Players`：三维期间玩家身体的绘制与受伤／使用物品限制。
- `DimensionalTerraria/Rendering`：三维区块网格、贴图、深度缓冲、相机与落点提示。
- `tests/SpatialTests`：145项逻辑检查，覆盖空间、飞行、生命周期、敌怪目标、手持姿态、交互、群系、图集裁帧、羊蛋落点与原生尺寸像素素材格式。
- `tests/LocalizationTests`：使用 tModLoader 同版本的 HJSON 解析器检查中英文本地化文件。
- `tests/EngineApiTests`：Build.ps1在打包前进行21项检查，包含原版交互、角色存档、羊与武器、27种方块的真实注册及实例创建、RawImg原生读取、配置页面拆分、羊蛋消耗保护，以及原版ItemSlot拿取／移动／拆分；不创建游戏窗口或音频引擎。
- `tests/AssetTests.ps1`：Test.ps1在Windows中读取三张真实PNG，用运行时相同的裁帧逻辑检查Steve、羊各8帧及剑的单帧素材。
- `tests/AudioWorkaroundTests.ps1`：使用项目内的隔离目录验证音频补丁的只读查询、安装、重复安装、还原和外部修改保护，不修改真实Steam目录。
