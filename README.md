# MineTerraria

将 **Minecraft** 的方块与生物带入 **Terraria**，并允许玩家飞出二维地图，在第一人称三维视角下观察、建造和战斗。

当前版本：**0.24.2** · tModLoader 1.4.4 · 单人模式

MineTerraria 由 Minecraft 的 Mine 与 Terraria 拼合而成。原内部模组标识 `DimensionalTerraria` 保持不变，原有角色、世界与模组物品沿用该标识。公开源码目录与工程文件现为 `MineTerraria/MineTerraria.csproj`，GitHub 根目录也使用新名称。

## 玩法

- 按 V 在二维与三维之间切换。三维地图是有厚度的方块与背景墙平面，玩家可以在地图正面飞行，并在合法位置返回二维。
- 第一人称快捷栏、背包、工具挥动、挖掘碎屑、掉落物拾取、武器命中与血条反馈。
- 可选择探索迷雾；开启时隐藏未探索地形，并阻止返回和操作未探索位置。
- Minecraft 风格的木板、工作台、箱子、船、矿物块、红石块、脉冲器、活塞与漏斗。
- 羊、村民、中立铁傀儡和生成蛋。受惊村民可召唤铁傀儡，铁块 T 形结构与南瓜也可召唤。
- Steve 独立角色外观；高维投影剑、镐与护甲采用下界合金外观。
- 新材料下界合金与完整的正常物品合成途径；烟花可在两个模式中提供推进。

三维期间世界继续运行，玩家脱离二维敌怪仇恨。Boss 与既有部件留场等待，AI 阶段暂存，返回二维后恢复正常索敌；伤害和死亡处理继续执行。

## 安装

1. 安装 Terraria 与 tModLoader。本版在 Windows 的 tModLoader **v2026.08.3.0 / Terraria 1.4.4.9** 上编译并验证。
2. 将 `MineTerraria-v0.24.2.tmod` 放入 tModLoader 的 Mods 文件夹，仅保留一个版本。
3. 启用 **MineTerraria**，进入单人世界。在模组配置中调整三维选项。

从旧版本升级时无需改名已有角色或世界。角色选择页的“新建 Steve 角色”用于创建独立外观，不会替换所有角色。

## 操作

| 操作 | 默认按键 |
| --- | --- |
| 切换二维／三维 | V，可重绑定 |
| 返回三维出发位置 | B，可重绑定 |
| 打开三维背包 | E，可重绑定 |
| 转动视角 | 鼠标；灵敏度可调 |
| 三维移动 | WASD，W 沿完整视线前进 |
| 上升／下降 | 空格／Shift |
| 加速 | Ctrl |
| 切换快捷栏 | 数字键／滚轮 |
| 挖掘／攻击 | 左键 |
| 放置／使用生成蛋／烟花 | 三维右键 |
| 三维菜单／释放鼠标 | Esc |
| 二维蹲下 | 在实心地面按住 S |

烟花在二维中用左键朝鼠标使用，在三维中用右键朝准星使用。聊天命令 `/dimension` 切换模式，`/dimension back` 返回出发位置。

## 合成与物品图鉴

木板与首张 Minecraft 工作台可徒手制作，其余本模组配方均要求靠近 **Minecraft 工作台**。三维背包目前只支持整理物品，合成仍在二维进行。

下界合金：**4 狱石锭 + 4 叶绿锭 + 1 夜明锭 → 1 下界合金**。投影剑／镐／头盔／胸甲／护腿分别需要 2／3／5／8／7 个下界合金；剑与镐另需橡木板。完整配方见 [配方表](docs/RECIPES.md)。

模组设置保留“物品图鉴”和“原版物品图鉴”：可搜索，点击领取 1 个，Shift＋点击领取最多 64 个。调试远程枪仅在物品图鉴中保留，无合成配方。召怪按钮、永久白天、录制快捷键和诊断文字已移除。

## 从源码构建

需要 Windows PowerShell、.NET 8 SDK 和本地 tModLoader。项目输出、临时运行时与本地游戏依赖不纳入 Git。

```powershell
.\scripts\Test.ps1
.\scripts\Build.ps1 -TmlDirectory '你的Steam库\steamapps\common\tModLoader'
```

直接 `dotnet build` 只编译程序集；打包请使用 `Build.ps1`。脚本在被 Git 忽略的 `.dev/package-source/DimensionalTerraria` 临时目录中调用官方打包器，使源码目录更名后仍保留原存档标识。

`Test.ps1` 校验核心逻辑、本地化与素材；`Build.ps1` 使用指定引擎运行原生 API 检查并执行官方打包。新包输出至 `artifacts/MineTerraria-v版本.tmod`，同版本重建会添加后缀并保留已有文件。`scripts/Setup.ps1` 可下载历史固定版开发依赖；本版推荐使用上述已安装的 Steam 引擎路径。

上传源码时正常提交项目、脚本、测试与文档即可；`artifacts/` 下的 `.tmod` 可作为 GitHub Release 附件单独上传。

## 当前限制

- 主要支持单人游戏；未承诺多人或大型玩法模组兼容。
- 三维建造写回原地图，不创建 Z 轴方块层。身体、地形、距离、支撑与探索限制仍需满足。
- 生物沿地图平面以精灵显示，复杂肢体与特殊自定义绘制可能需要额外适配。
- 常规武器、天顶剑、飞龙与钻头已有适配；并非所有原版弹幕、特殊武器 AI 都能完整映射到三维。
- Boss 的无目标完整战斗 AI 尚未实现，三维中暂停其决策与阶段推进。
